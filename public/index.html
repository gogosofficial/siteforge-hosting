Hosting, um das du dich nicht kümmern musst

Der Code deiner Website wird auf GitHub versioniert und über Cloudflare Pages veröffentlicht. So sieht der Weg vom Code bis zu deiner Adresse aus:

  1. GitHub

    Code sicher abgelegt

    Der gesamte Website-Code liegt in einem GitHub-Repository. Jede Änderung ist nachvollziehbar und lässt sich bei Bedarf zurücknehmen.

  2. Cloudflare Pages

    Automatisch veröffentlicht

    Cloudflare Pages übernimmt den Code von GitHub und liefert deine Website aus – inklusive Cloudflare-Schutz in jedem Paket.

  3. dein-projekt.pages.dev

    Unter deiner Adresse erreichbar

    Jede Website startet mit einer kostenlosen pages.dev-Adresse. Eine eigene Domain binden wir auf Wunsch über Cloudflare an.

Starter & Pro: komplett betreut

Code und Veröffentlichung laufen über die Accounts von SiteForge. Du musst dich um nichts Technisches kümmern und gibst Änderungen einfach als Update in Auftrag.

Elite: deine eigenen Accounts

Du erhältst einen projektbezogenen GitHub-Account und eine eigene Cloudflare-Pages-Verwaltung – mit vollem Zugriff auf Code und Inhalte.

In vier Schritten zur fertigen Website

Von der ersten E-Mail bis zum Launch weißt du jederzeit, was als Nächstes passiert.

  1. Anfrage senden

    Du schickst mir per E-Mail dein gewünschtes Paket, eine kurze Projektbeschreibung und deine Ideen oder Materialien.

  4. Launch & Updates

    Der Code wird auf GitHub bereitgestellt und über Cloudflare Pages (zunächst mit pages.dev-Adresse) veröffentlicht. Danach begleite ich dich mit monatlichen Updates.

Häufig gestellte Fragen

Die wichtigsten Antworten zu Adresse, Hosting, Updates und Kosten. Deine Frage ist nicht dabei? Schreib mir einfach.

Frage stellen
Was kostet eine Website bei SiteForge?
Die Preise gibt es auf Anfrage, weil sich die Kosten nach Umfang, Design und gewünschten Funktionen richten. Du erhältst vorab ein unverbindliches, individuelles Angebot, in dem einmalige und laufende Kosten klar aufgeschlüsselt sind.
Welche Adresse bekommt meine Website und ist eine eigene Domain möglich?
Jede Website erhält zunächst eine kostenlose pages.dev-Adresse über Cloudflare Pages. Wenn du bereits eine eigene Domain besitzt oder nutzen möchtest, binden wir diese über Cloudflare an deine Website an.
Wie funktioniert das Hosting bei Starter, Pro und Elite?
Alle Websites werden in HTML und CSS erstellt. Bei Starter und Pro liegt der Code auf dem GitHub-Account von SiteForge und wird über Cloudflare Pages durch SiteForge veröffentlicht und verwaltet. Beim Elite-Paket richten wir einen eigenen projektbezogenen GitHub-Account sowie eine projektbezogene Cloudflare-Pages-Verwaltung für dich ein.
Kann ich meine Website später selbst bearbeiten?
Bei Starter und Pro musst du dich um nichts Technisches kümmern: Du hast keinen direkten Code-Zugriff, sondern gibst Änderungswünsche über deine monatlichen Updates an mich weiter. Wenn du Inhalte und HTML-/CSS-Code jederzeit selbst bearbeiten möchtest, ist das Elite-Paket mit eigenem GitHub-Account die richtige Wahl (Bearbeitung direkt im Code/Repository, kein grafisches Baukasten-System).
Wie laufen die monatlichen Updates ab?
Je nach Paket sind 3 (Starter), 5 (Pro) oder 7 (Elite) Updates pro Monat durch SiteForge enthalten. Du schickst mir deine Text-, Bild- oder Inhaltsänderungen per E-Mail. Was genau unter ein reguläres Update fällt und wie umfangreichere Umbauten geregelt sind, legen wir vorab im Angebot fest.
Wie erreiche ich den Support?
Direkt per E-Mail an direktanfragepaul@gmail.com. Du hast einen festen Ansprechpartner, der deine Website selbst gebaut hat – ohne Callcenter und ohne Ticket-System.
Wie stelle ich eine Anfrage?
Klicke auf einen der Anfrage-Buttons. Dein E-Mail-Programm öffnet sich mit einer vorbereiteten Vorlage an direktanfragepaul@gmail.com. Hast du kein E-Mail-Programm eingerichtet, kopierst du die Adresse einfach im Kontaktbereich.
